# R-Vent HVAC Solutions Website
Static HTML/CSS/JS site ready for GitHub Pages.

## Publish free with GitHub Pages
1. Create a public GitHub repository (example: `rventhvac-website`).
2. Upload all files and the `assets` folder from this package.
3. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. GitHub will provide the HTTPS URL after deployment.
