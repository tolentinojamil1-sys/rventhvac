# R-Vent HVAC Solutions Website
Static HTML/CSS/JS site ready for GitHub Pages.

## Company-only GitHub Pages address

The current project URL includes the owner's GitHub username. To use a free company-branded address, create a GitHub organization named `rventhvac` (if available) and a public repository in that organization named exactly `rventhvac.github.io`. Upload the site files and `assets` folder there. In Settings → Pages, choose Deploy from a branch, `main`, and `/ (root)`. The resulting site address will be `https://rventhvac.github.io/`. Repository creation and Pages activation require access to the company organization.

## Quote requests

The quote form prepares an email addressed to `rventhvac@gmail.com` in the visitor's email app. The visitor must review and send it; this static GitHub Pages site does not automatically store or deliver form submissions. The direct email link beside the form provides a fallback when no email app is configured. To receive submissions directly in an inbox without requiring the visitor's email app, connect a form service or server endpoint and test its delivery before advertising automatic submission.
